# Shadowing-based sensitivity analysis
This branch contains the code for the test cases used in the article: Thakur, P., Nadarajah, S. Adjoint of Least Squares Shadowing: Existence, Uniqueness and Coarse Domain Discretization. J Sci Comput 105, 47 (2025).

For test case 1, run file `adjoint_main.py`.

For test case 2, run file `coupled_oscillators/adjoint_main.py`.
